# Documentazione Group Chat

Inizia da [stato corrente](project/current-state.md), poi apri il task attivo in `tasks/active/`. L'[overview](project/overview.md) definisce obiettivo e scope, l'[architettura](project/architecture.md) i confini tecnici e la [roadmap](project/roadmap.md) la progressione.

Usa `tasks/` per il lavoro verificabile e `decisions/` solo per decisioni architetturali significative. `learning/` contiene spiegazioni concise dei concetti introdotti nelle milestone successive.
