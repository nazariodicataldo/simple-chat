# Documentazione Simple Chat

Inizia da [stato corrente](project/current-state.md), poi apri il task attivo in `tasks/active/`. L'[overview](project/overview.md) definisce obiettivo e scope, l'[architettura](project/architecture.md) i confini tecnici e la [roadmap](project/roadmap.md) la progressione.

Per il deploy pubblico usa il [runbook Render](runbooks/deployment-render.md); per
le motivazioni tecniche e i compromessi leggi la [guida learning](learning/deployment-render.md).

Usa `tasks/` per il lavoro verificabile e `decisions/` solo per decisioni architetturali significative. Le anomalie, il debito tecnico e le correzioni emerse fuori scope sono raccolti in [issues/](issues/README.md). `learning/` contiene spiegazioni concise dei concetti introdotti nelle milestone successive.
