# Decisioni architetturali (ADR)

Registra qui solo decisioni significative e non banali con file `0001-nome-decisione.md`, a numerazione progressiva. Non usare gli ADR come diario di task o lista di opzioni ipotetiche.

Per crearne uno, copia [il template ADR](adr-template.md) e assegna il prossimo numero disponibile.
