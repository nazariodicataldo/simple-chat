# Docker

Da usare nella Milestone 5. Docker Compose verra' introdotto per gradi: prima PostgreSQL e Redis, poi backend, frontend, Reverb, worker/Horizon ed eventualmente reverse proxy. Non e' un prerequisito delle milestone applicative precedenti.

Ogni servizio introdotto deve avere un motivo osservabile, comandi di avvio riproducibili e uno smoke test. Consultare la documentazione Docker ufficiale relativa alla versione in uso prima di scrivere configurazioni.
