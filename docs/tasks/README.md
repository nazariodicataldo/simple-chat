# Task

Ogni task parte da `active/` usando [il template](task-template.md). Quando tutti i criteri sono verificati, aggiorna il file con evidenze e spostalo in `completed/`.

Prima di iniziare, leggi [AGENTS.md](../../AGENTS.md), [stato corrente](../project/current-state.md), il task attivo e solo la documentazione collegata. Un task non diventa completo se un controllo pertinente fallisce, manca senza motivazione dichiarata, esistono modifiche fuori scope non approvate o i criteri non sono dimostrati.
